## 2. 市場構造の要点(カテゴリ指紋の要約)

1. **権限訴求の「宣言と機構のギャップ」**: 権限・アクセス制御に言及する直接競合7/18はすべて一文宣言型か管理機能型(Gemini ja)で、機構を説明するLPは0/18(conv-05。追観察のGemini Enterprise jaを含む)。
   一方ペイン側では、当事者は機構レベルで苦しんでいる(「ザルRAG」「ドメイン全体委任ではACLが機能しない」「DMがサマリーに混ざった」)。
   → 宣言ではなく**機構の開示**で語ることが、観察範囲で競合が最も薄い差別化余地(ws-01。市場全体での不在の証明ではなく機会仮説)。
2. **日本市場の信頼構成の非対称**: 日本の隣接5社は権限モデルに触れず、ISO・国内サーバー・学習不使用で信頼を構成(conv-04)。
   権限**機構**を主役に据えた日本語LPは観察範囲(ja-JP 8件)で不在(ws-02)。ただし権限への機能言及はM365/Notionの日本語LPに実在するため、
   「権限を語るのは当社だけ」型の主張は禁止(skeptic指摘2)。
3. **leisenが使えない証明手段が、カテゴリの標準証明手段**: ロゴ・削減数値・認証バッジ(conv-02)はclaim-ledgerで禁止。
   代替の信頼構成として、反例Keycloak(標準準拠+アーキ図のみで成立)とOSS慣習(self-host・透明性、conv-06)が実在の参照点になる(var-01の「構造型」)。
4. **引き算の不在**: 全LPが機能加算型。「しないこと」(ACL複製しない・データ預からない・インデックス持たない)を約束の中心に置く構成は0件(ws-03)。
   leisenの設計思想(可動部品最小・不変条件)と一致し、かつ実装者の失敗談(pc-04/05)への応答になる。
5. **AI疲れの兆候**: Slack AIの「AIの登場でかえって悩みが増えた?」という逆張り(反例)と、ペイン側のPoC止まり・「幻想」批判は同じ現象を指す。
   「もう1つのAI製品」として登場するより、「AI導入が止まる構造問題への応答」として登場する方が証拠と整合する。

## 3. 戦略への含意(ポジショニングの入力)

- 最有力の入口ペインは **pc-04(権限・見えすぎ)**: 外部証拠がhighで、買う人自身の一次ペインで、白地(ws-01/02)と重なる。
- 対抗軸は **pc-03(PoC止まり)入口**(方法論・段階導入を前面に)と、**pc-05×内製対比入口**(ザルRAG・運用負債からの解放)。
  この3つは説得の起点が実質的に異なるため、ポジショニング3案の骨格に使える。
- 証明戦略はロゴ・数値の代替として「機構の開示(アーキ図・不変条件)+OSS透明性+限界の正直な開示(ws-05)」で構成する。
  ただしKeycloak型の成立は既得名声込みの観察であり、ゼロ知名度での再現は**未検証の賭け**として計測対象に登録する(skeptic指摘5)。
- **対スイートAI反論処理を必須スロット化**(skeptic指摘4): ターゲットの最も摩擦の低い代替は「契約済みスイートのAI有効化」
  (M365 Copilotは権限・ラベル継承をネイティブ主張)。leisenが必要になる条件=「複数SaaSに分散し単一スイートに寄せられない環境」
  (brief記載の10〜30ソース前提、fact-010)を明文化し、単一スイートで足りる企業を正直に対象外とする。
  各ポジショニング案は「それ、Copilot/Notionでよくない?」への回答を必ず持つこと。
- 「探す時間1時間5分/日」等のベンダー調査数値は、使う場合「従業員2,000人以上対象・2022年・検索ベンダー調査」の3点注記必須(skeptic指摘6)。
- Stage 5では流入シナリオを最低2つ仮置きし、各メッセージ案の流入前提を明記する(skeptic指摘7。広告観察0件のため)。
- 禁止事項の再確認: 導入実績・削減数値・「問い合わせゼロ」約束・権限逸脱ゼロの保証表現(clm-012/013/016、ev-p14)。
  加えてJIPDEC 59.9%/64.1%を「見えすぎ」文脈で引用しない(skeptic指摘1)。

## 4. 分析の限界

- 広告観察0件のため「traffic source × ad promise × conversion」の広告側整合は未検証。Stage 5で流入シナリオを仮置きして代替する(skeptic指摘7)。
- Gemini Enterprise日本語LPはskeptic指摘3を受けて追観察済み(src-m18: 機構説明なしを確認、白地判定は維持)。Glean日本語LPは404で存在確認できず。フォーム摩擦・モバイル差分は未観察のまま。
- white spaceは「観察18件内での不在」であり、市場全体での不在の証明ではない(全white space主張に分母付き表記を適用済み)。
- 本分析はskeptic-review.mdの8条件を遵守してStage 4以降に引き継ぐ。
