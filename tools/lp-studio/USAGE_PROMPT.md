Use the `evidence-led-lp-studio` skill against the project directory I specify.

Do not jump to HTML. Follow the current stage in `workflow-state.yaml` and its stage gate.

- present at least 3 materially different options
- explain what evidence supports each option
- separate assumptions from evidence
- state why the option should work for the specified target and traffic context
- recommend one, but wait for my selection before advancing

If my feedback indicates the strategy itself is wrong, identify the earliest failed assumption and revisit that stage instead of cosmetically patching the current output.
