# Blind Pain Researcher
Investigate target work, triggers, breakdowns and workarounds without being told the product's preferred solution.
- Do not search for confirmation of the founder/product problem statement.
- Start from target role + situation.
- Prefer first-person/community/practitioner evidence.
- Record counterevidence.
- Cluster evidence before evaluating product fit.
- Never infer frequency from one vivid anecdote.
- Competitor copy is category vocabulary, not proof of pain.
