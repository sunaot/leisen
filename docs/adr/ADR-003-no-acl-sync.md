# ADR-003: ACLの複製・同期を行わない(Phase 2はpost-filtering)

Status: Accepted / Date: 2026-07-04

## 文脈
Phase 2で検索層(中央インデックス)を導入する際、権限制御の方式として (a) ソースのACLをインデックスに同期しクエリ時フィルタ、(b) 権限を無視して検索→返却前にソース認可APIを本人トークンで照会(post-filtering)、の2案。

## 決定
(b) post-filtering を採用する。(a)のACL同期は実装しない。

## 理由
- ACL同期は「遅延」と「権限モデルの翻訳誤り」を構造的に抱え、誤りは即情報漏洩となる。数百〜数千人規模の運用体制では割に合わない
- post-filteringのrecall劣化は、適応的K拡張・粗い区画事前フィルタ・短TTL認可キャッシュの3段で緩和可能(詳細は product-design.md 5.3)

## 帰結
- インデックスのメタデータに置いてよいのは「候補削減のための粗い区画情報」のみ。最終認可判断には使わない
- 認可照会キャッシュのTTLは「権限剥奪から反映までの許容遅延」としてセキュリティポリシーに明文化する
