# ADR-013: プライバシー・保持・ログ閲覧方針

Status: Proposed(人間の決定待ち: 情報セキュリティ・法務・労務) / Date: 2026-07-05

## 文脈
本人権限検索はSlackのDM・プライベートチャンネル等を含む。認可上は正当(本人は見てよい)だが、fetchedDocIds等のメタデータが中央監査ログに全件記録されるため、管理者が「誰がいつどのDMを参照したか」を閲覧できる。監視ツール化の懸念、就業規則・労使協議、個人情報保護の論点であり、日本企業への導入では確実に問われる。また、回答に転写された機密はチャット履歴に残り、その後の権限剥奪に遡及しない。

## 提案
1. deployment.yamlに `connectors[].privateScopes: excluded | consent | included` を設け、**既定は excluded**(DM・プライベートスコープを検索対象外)とする
2. プライベートスコープのdocIdは監査ログ上で不可逆化する(または記録しない)選択肢を設定可能にする
3. 監査ログの閲覧権限・目的・保持期間を導入時の利用規程で限定する(導入プレイブックのテンプレート化)
4. チャット履歴の保持期間・エクスポート可否・共有禁止をT-009の要件とする
