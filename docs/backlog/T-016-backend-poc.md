# T-016: 検索バックエンドPoCと選定

## 位置づけ
文書検索モジュール実装(T-015含む)の前提。Q3冒頭、目安2週間。候補の洗い出しから行う(現時点で候補は確定していない — ADR-006/008)。

## 前提(人手)
自社共有ドライブの実データサンプル(日本語Office/PDF中心、権限的に安全な部分集合)の提供。

## 内容
- 着手時点でのOSS検索エンジン候補を改めて洗い出す(全文+ベクトルのハイブリッド、ローカル埋め込みの可否、日本語品質、ライセンス、運用複雑度を観点に)
- 同一コーパスを投入し、評価ハーネス(T-008)を流用して比較
- 評価軸: 日本語検索精度、ローカル埋め込みの検索品質、適応的K拡張時のレイテンシ、運用複雑度(プロセス構成・バックアップ・全再構築時間)、ライセンス

## 受け入れ条件

- [ ] 非採用候補の再評価条件が記録される
