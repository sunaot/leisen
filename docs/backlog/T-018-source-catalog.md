# T-018: Source Catalog / 全社公開マップ(Phase 1.5)

## 目的
describe常時コンテキスト方式(product-design.md 4.3)のスケール限界への対処と、俯瞰ニーズの一部先取り(product-design-v3.md §7)。

## 内容
- 薄いSource Catalog: ソースごとの「何がありそうか」「検索に使う語彙」「代表コンテナ」。文書本文の要約は含めない
- 本人権限フィルタ版(ユーザー単位キャッシュ、不変条件4)と全社公開版を分離
- 全社公開マップ: 全員可視の情報のみを入力とする(入力が全員可視なら要約漏洩が構造的に起きない)。Slack由来のcontent/metadata(本文・permalink・channel/user/file名・timestamp)は入力に含めない(ADR-014、不変条件7)
- OrchestratorのdescribeをCatalogで置換し、コンテキストサイズを計測

## 受け入れ条件
- [ ] カタログ生成が本人権限のみで行われることがテストされている
- [ ] 全社公開版の入力が全員可視情報のみで構成されることの検証手順がある
- [ ] describe方式との比較(初手選択品質、コンテキストサイズ)が評価ハーネスで計測される
